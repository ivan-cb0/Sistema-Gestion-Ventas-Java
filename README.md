# Sistema de Gestión de Ventas para Tienda de Tecnología

## Descripción
Este proyecto fue desarrollado como trabajo final del curso Programación Orientada a Objetos. El sistema permite gestionar las ventas de una tienda de tecnología mediante una aplicación de escritorio desarrollada en Java y MySQL.

## Tecnologías utilizadas
- Java
- Java Swing
- MySQL
- JDBC
- NetBeans IDE

## Funcionalidades
- Registro de usuarios
- Inicio de sesión
- Catálogo de productos
- Carrito de compras
- Confirmación de compras
- Historial de pedidos

## Archivos del repositorio
- `ProyectoTienda.zip`: Proyecto completo de NetBeans.
- `tienda.sql`: Script de la base de datos.
